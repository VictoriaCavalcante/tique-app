# tique-app
A idéia principal é reunir funcionalidades suficientes para registrar dívidas e cobrar via whatsapp, o público alvo trata-se de trabalhadores autônomos (revendedores, vendedores, cabeleireiros) que possuem dificuldade para centralizar e gerenciar registros financeiros da vida profissional, fornecendo também uma visão holística dessas finanças.
